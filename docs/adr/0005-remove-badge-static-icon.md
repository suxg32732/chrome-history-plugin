# 移除数量角标，回归静态图标

v0.3.1 用户决定：工具栏图标不再显示数量。数量角标自 v0.2.1 引入（ADR-0003，原生 badge 遮挡图标）、v0.3.0 改为右下角自绘小圆点，如今用户不再需要「不看弹窗即知条数」。决定：删除 OffscreenCanvas 自绘逻辑与整个后台 service worker（manifest 移除 `background` 段，`background.js` 删除），工具栏图标回归静态 `icons/*.png`——该静态图按 24 单位 viewBox 全幅渲染（图案实际占宽约 87.5%），与 v0.3.0 放大后的自绘图标观感一致，无需重新生成；`countTextFor` 及其测试一并移除，`RECENT_LIMIT = 99` 保留（ADR-0004）。

**Considered Options**：
- 保留 service worker 仅绘制纯图标 — 否决：与静态图标完全等价，白付唤醒与维护成本。
- 保留角标但默认隐藏、留配置开关 — 否决：无配置界面需求，徒增状态。
- **移除后台与角标，回归静态图标 — 采用**：简化优先，MV3 扩展不再含任何后台逻辑。

**Consequences**：
- 可查看数量只能在弹窗内感知（列表长度），工具栏不再实时反映历史变化。
- `chrome.history` 权限仍由弹窗取数使用，权限声明不变。
- 从旧版本升级重载后，Chrome 的角标状态随扩展重载自动清空，无需迁移代码。
- ADR-0003 的自绘角标决策自本 ADR 起失效；ADR-0004 的「上限 99」与「显示所有历史」继续有效。
