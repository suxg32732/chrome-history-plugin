# 手动验收清单（Manual Acceptance Checklist）

无头单元测试（`model.test.mjs`、`history-source.test.mjs`）之外的端到端验证。在 Chrome 152 加载解压扩展后执行。

## 前置

- Chrome 打开 `chrome://extensions`，开启「开发者模式」
- 「加载已解压的扩展程序」→ 选择本仓库目录
- 安装时请求「历史记录」与 favicon 相关权限，需允许

## 用例

1. 工具栏扩展图标为蓝色「历史」图标（时钟 + 逆时针箭头，与 Chrome 内置历史图标同款），**无数量角标**。
2. 点击工具栏图标，弹窗默认可见约 10 条，向下滚动可查看全部 99 条（不足 99 条时显示实际数量）；每行行首有灰色序号，从 1 开始连续递增。
3. 每条记录行首为网站真实 favicon，与 `chrome://history` 中的图标一致；标题、相对时间正常。
4. `chrome://` 内部页等无真实图标的记录行首显示首字母头像。
5. 点击任意一条，在**前台新标签**打开该网址。
6. 长标题被截断为省略号。
7. 加载过程中显示「加载中…」；历史为空时显示「暂无浏览记录」。
8. 在扩展管理页撤销「历史记录」权限后重载弹窗，显示「无法加载浏览记录，请检查历史记录权限」（而非空白）。
9. 全程无第三方网络请求（favicon 来自 Chrome 本地缓存，不连任何外部服务）。
10. 点击弹窗底部「显示所有历史」，在前台新标签打开 `chrome://history`，弹窗随之关闭。

## v0.4.0 新增：关键词过滤（见 ADR-0006）

11. 打开弹窗即自动聚焦顶部搜索框，可直接打字；向下滚动列表时搜索框保持可见（搜索框位于列表滚动容器之外）。
12. 输入关键词**即时**过滤、无需回车；匹配**标题或网址**的**子串**、不区分大小写；过滤后序号从 1 **连续重排**，不出现跳号。
13. 关键词无匹配时，列表区显示「**没有匹配的记录**」（区别于历史为空时的「暂无浏览记录」），且搜索框仍可见、可编辑。
14. 按 **Esc** 清空关键词并恢复完整列表，焦点仍留在搜索框内；搜索框本就为空时按 Esc 无副作用。
15. 关闭弹窗再打开，搜索框为空（关键词不跨次保留），列表恢复完整。
16. 过滤不触发新的取数：输入/清空关键词时列表**瞬时**更新，不出现「加载中…」闪烁。**不要用 DevTools 的 Network 面板判定**——`chrome.history.search` 是扩展 API 的进程间调用，不是网络请求，Network 面板本就为空；严格的调用次数已由验证层用桩计数确认为 1 次。
17. 撤销「历史记录」权限后重载弹窗，显示「无法加载浏览记录，请检查历史记录权限」；此时在搜索框输入**不会**把该文案顶掉。
18. 弹窗整体不出现外层滚动条（搜索框新增后 `body` 600px 上限仍未被撑破）。

> **注（勿当缺陷）**：本插件的过滤**刻意**使用宽松的子串匹配，而 `chrome://history` 使用「分词 + 前缀（≥3 字符）+ AND」语义。同一关键词（如 `domain`）在插件能命中 `example.org`、在内置页命中不了，属**有意为之**（ADR-0006）。
>
> **注**：`.list` 的 `max-height` 由 500px 降为 455px，为搜索框腾出空间；首屏可见行数由约 11 行变为约 10 行（行高约 43px）。
